模块按 WPF 标准分为 Views/（XAML + 轻量 code-behind）与 ViewModels/（业务编排与状态）两层，依赖方向单向：Views → ViewModels → Services/Models/Helpers。
- MainViewModel.cs 作为 MVVM 核心，持有 TcpServerService 实例并通过事件订阅设备连接/日志/场景树/命令结果回调，使用 ConcurrentDictionary<string, TaskCompletionSource<CommandResult>> 实现带超时的异步指令-响应匹配；所有 UI 更新通过 Application.Current.Dispatcher.Invoke 切回 UI 线程。
- MockServerViewModel.cs 封装 SC 协议模拟面板，通过 ProtocolRegistry 枚举可用协议、ProtoMessageBuilder 动态构建 protobuf 消息并调用 MainViewModel.SendMockProtocolAsync 下发，同时维护最近 100 条发送记录并以去抖方式持久化到 sent_requests.json。
- ProtoGenViewModel.cs 提供 proto→C# 代码生成子面板，封装 protoc 探测与执行，并将配置通过 ProtoGenSettingsStore 持久化。
- Views/ 下 FileRequestDialog / HotUpdateDialog 为简单 Window，仅负责收集用户输入后返回 DialogResult；MockServerView 为纯 UserControl，DataContext 由宿主 MainWindow 注入 MockServerViewModel。
- 每个 ViewModel 内嵌自实现的 RelayCommand 类以支持 ICommand 绑定，属性统一通过 INotifyPropertyChanged 暴露。
