- ViewModel 统一实现 INotifyPropertyChanged，并通过 CallerMemberName 辅助方法 OnPropertyChanged 触发属性变更通知。
- UI 交互通过 ICommand 暴露，采用内嵌 RelayCommand 类封装同步/异步 Execute 与 CanExecute 条件判断。
- 跨线程回调（TcpServerService 事件）一律使用 Application.Current.Dispatcher.Invoke 将 UI 更新调度到 UI 线程。
- 长耗时操作（如 protoc 生成、网络发送）以 async/await 配合 TaskCompletionSource 或 Task.WhenAny 超时模式处理，避免阻塞 UI。
- 用户偏好与历史数据通过独立的 *Store 类（DeviceAliasStore、SentRequestsStore、ProtoGenSettingsStore）进行 JSON 持久化，ViewModel 仅消费接口。
- 对话框类保持极简 code-behind，仅负责读取控件值、设置属性并返回 DialogResult，业务逻辑交由调用方 ViewModel 处理。
